# SnapInsight — On-device AI Explanations

[English](README.md) | [简体中文](README.zh-CN.md)

SnapInsight is a Chrome extension that explains short text selected on a webpage. Select a word or phrase, hover over the `SI` trigger beside it, and receive a layered explanation from Chrome's on-device Prompt API.

Explanations are generated by a local model managed by Chrome. SnapInsight does not require a desktop app, Python service, or Ollama, and it does not send selected text to a SnapInsight backend.

![SnapInsight in-page card example](docs/assets/readme-in-page-card-example.png)

## How it works

- Select 1–20 Chinese characters or English words
- Hover over the `SI` trigger near the selection to generate a short explanation
- Click `查看更多` (Show more) to generate a detailed explanation
- Copy, regenerate, close, or cancel an in-progress response
- Press `Esc` to close the card

Only text explicitly selected by the user is passed to the on-device model. SnapInsight does not collect the page title, surrounding paragraphs, or other page context.

## Requirements and limitations

- Chrome 138 or later
- A device, storage configuration, and region supported by Chrome's built-in AI
- An internet connection during first-time setup so Chrome can download the on-device model

Prompt API device coverage and language support may change between Chrome versions. Chinese output has been verified in a real Chrome environment, but it is not a browser capability that SnapInsight can independently guarantee.

The extension works only on ordinary pages where Chrome permits Content Script injection. It does not run on restricted pages such as `chrome://` pages or the Chrome Web Store. Access to `file://` pages must be enabled separately on the extension management page.

## Development and installation

```bash
cd extension
npm ci
npm run check
npm test
npm run build
```

Then:

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select `extension/dist`
5. On first install, the device status page opens automatically; click **Prepare local model**

If an older build is already loaded, click **Reload** on the extension card and then refresh the page being tested.

## Architecture

```text
Webpage Content Script / Shadow DOM card
        ↕
Chrome Prompt API / on-device model

Manifest V3 Service Worker
        └── first-run setup and toolbar entry point
```

The Prompt API runs directly in the Content Script's isolated extension world. Selection, generation, streaming, and cancellation remain within the current page instance. The Service Worker does not perform inference; it only handles first-run setup and the toolbar entry point.

## Permissions and privacy boundaries

- The Content Script reads only user-selected text and its selection coordinates
- No surrounding page context is collected
- No SnapInsight server or third-party model API is contacted
- Selected text and generated results are not saved
- No telemetry, advertising SDK, or remotely hosted code is used
- Model download and execution are managed by Chrome

The Manifest uses `content_scripts.matches: ["<all_urls>"]` so the `SI` trigger can appear after a selection on an ordinary webpage without requiring the user to click the toolbar first. Chrome Web Store treats this as access to all websites. SnapInsight uses that access only to detect an explicit text selection, obtain its coordinates, and render the explanation card. It does not read surrounding paragraphs, page titles, form content, or browsing history.

The Manifest does not declare an additional `host_permissions` field and does not request `tabs`, `history`, `webRequest`, `offscreen`, or similar permissions.

See the [compatibility baseline](docs/product/compatibility.md), [privacy policy](docs/product/privacy-policy.md), and [Chrome Web Store checklist](docs/product/chrome-web-store-checklist.md).
